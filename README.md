# Dev-journal

Este repositorio contiene mis notas, errores documentados y aprendizajes durante mi avance por The Odin Project y el estudio de desarrollo web.

A medida que adquiera nuevas habilidades en HTML, CSS y JavaScript, iré mejorando la interfaz y la funcionalidad de este sitio.

## Estructura del repositorio

* `/notas`: Archivos HTML con la documentación de conceptos y errores por módulo.
* `/css`: Estilos aplicados a este diario.
* `index.html`: Navegador principal de las notas.
