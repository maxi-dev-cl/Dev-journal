  • Ejercicio número 4 de Odin project, Chaining selectors
  • Aprendí a usar los Chaining selectors, si quieres modificar un elemento con 2 clases especificas y estas 2 están compartidas por otros elementos en otro orden, utilizas el siguiente orden: .class1.class2 y asi solo modificas al elemento que tenga exactamente esas 2 clases, esto también se puede aplicar combinando IDs, ejemplo: 
    .class1#ID1{
                background-color:orange; }
  • También aprendí a usar el Descendant combinator, resumiendo sirve para aplicar CSS a elementos que se encuentre nested (almacenados dentro de otros), por ejemplo: div p{color:blue;} este código aplicara el color azul a todos los elementos p que estén dentro de un elemento div

Cascade

El CSS Cascade son los filtros/criterios en los cuales el navegador se basa para decidir cual regla aplicar, y los filtros son:

Specificity

  • Specificity:La regla más especifica de CSS tomara mayor importancia y se aplicara en la pagina web primero
  • Resumen de orden de prioridades:1:ID 2:Class,3:Type (p)
  • Y en el caso que sean del mismo nivel, por ejemplo solo clases, la regla que tenga más clases tendrá mayor relevancia
  • Los símbolos como * + virgulilla, espacios, no suman mayor especificación.

Inheritance

  • El concepto de Inheritance se refiere a que ciertos atributos del CSS que estén aplicados a un elemento, serán transferidos o heredados a sus descendientes como por ejemplo color, font-size, font-family
  • Uno puede encontrar una definición más formal de cada sintaxis en MDN, y revisando si tiene inheritance o no, el inheritance en cierto modo se puede cancelar apuntando con una clase o ID al elemento correspondiente

Rule Order

  • Resumen, si 2 reglas ya pasaron por los 2 filtros anteriores, la ultima que haya sido escrita se aplica al elemento

Box model, and block and inline

  • CSS tiene 2 tipos de cajas
  • El block, en el cual los objetos se apilan uno sobre otro, cada uno empezando en una linea nueva (display: block)
  • Y el inline element box type, estos se comportaran como parte del conjunto en el cual estén nested
  • Los middle ground inline-block elements, se comportan como los inline pero con propiedades de padding border y margin (display: inline-block)

Divs and spans

  • El Div es un contenedor de bloques genérico, es para acomodar grupos de elementos
  • Mientras que el Span es un generic inline container, es para acomodar dentro de los elementos
  • Resumen:div para grandes bloques, span para secciones pequeñas especificas
