  2. Asumí que tenia que crear una tercera clase en un ejercicio de Odin project
  3. Revisando la solución me di cuenta que no ocupe el selector list
  4. Mi solución:
    
            .first{
    background-color: black;
    color: white;
}

.second{
    background-color: yellow;
    color: black;
}

.size{
    font-size: 28px;
    font-family: Helvetica,'Times New Roman', Times, serif;
}
    Y la solución del ejercicio real: 
    .inverted,
.fancy {
  font-family: Helvetica, "Times New Roman", sans-serif;
  font-size: 28px;
}

.inverted {
  background-color: black;
  color: white;
}

.fancy {
  background-color: yellow;
}

  • 02/09/2026
  • Ejercicio número 4 de Odin project, Chaining selectors
  • Aprendí a usar los Chaining selectors, si quieres modificar un elemento con 2 clases especificas y estas 2 están compartidas por otros elementos en otro orden, utilizas el siguiente orden: .class1.class2 y asi solo modificas al elemento que tenga exactamente esas 2 clases, esto también se puede aplicar combinando IDs, ejemplo: 
    .class1#ID1{
                background-color:orange; }
  • También aprendí a usar el Descendant combinator, resumiendo sirve para aplicar CSS a elementos que se encuentre nested (almacenados dentro de otros), por ejemplo: div p{color:blue;} este código aplicara el color azul a todos los elementos p que estén dentro de un elemento div
