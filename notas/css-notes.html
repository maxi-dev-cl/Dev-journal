La estructura de reporte de errores o aprendizajes sera la siguiente

  1. Fecha
  2. ¿Que error ocurrio o que asumi mal? y ¿en cual contexto?
  3. La solución y correción que hice en el momento
  4. Mi codigo antes y despues en formato pequeño
  5. Enlace de MDN con el concepto que encontre utíl
  6. Conclución técnica
  1. 01/09/2026
  2. Asumi que tenia que crear una tercera clase en un ejercicio de Odin project
  3. Revisando la solución me di cuenta que no ocupe el selector list
  4. Mi solución:
    
            .first{
    background-color: black;
    color: white;
}

.second{
    background-color: yellow;
    color: black;
}

.size{
    font-size: 28px;
    font-family: Helvetica,'Times New Roman', Times, serif;
}
    Y la solución del ejercicio real: 
    .inverted,
.fancy {
  font-family: Helvetica, "Times New Roman", sans-serif;
  font-size: 28px;
}

.inverted {
  background-color: black;
  color: white;
}

.fancy {
  background-color: yellow;
}
  5. Selector List
  6. Conclusión:Usar el selector List osea .name,namename, para agrupar o aplicar modificaciones que compartan varios elementos de HTML, para asi evitar crear una clase por cada aspecto especifico a añadir en cada uno
